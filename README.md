# 状态侧边栏（dsh-status-sidebar）

一个本地 DSH（DeepSeek Harness）UI 插件：在左侧栏添加名为 **状态** 的入口，点击后在中栏内嵌
显示 <https://status.deepseek.com> 的实时页面，并用入口图标反映最新事件的 `Status:`。
